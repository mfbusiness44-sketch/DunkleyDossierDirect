# Dunkley Dossier Direct

Dunkley Lumber's app. First feature: BC Local Leaders, a map of British Columbia's 2026 local election winners, their objectives, forestry positions and local forestry news.

## Android
**[Download the latest app (APK)](https://github.com/mfbusiness44-sketch/DunkleyDossierDirect/raw/main/apk/Dunkley-Dossier-Direct-latest.apk)** - version 1.7

Open the downloaded file on an Android phone and allow installs from your browser when asked.

## iPhone and iPad
**[Open the app in Safari](https://mfbusiness44-sketch.github.io/DunkleyDossierDirect/)**, tap the **Share** button, then **Add to Home Screen**.
It installs with its own icon, opens full-screen, works offline, and updates itself whenever you are online.
Forestry news for each area is refreshed every morning by the *Daily forestry news* job in the Actions tab.

Installed copies update themselves: on each launch the app downloads newer map data and page updates
from `ota/` in the background, and offers a one-tap install when a newer APK is published in `apk/`.
